If you think you've found a security problem in AP Portal, please tell us so we can fix it.

How to report

Email [security contact email] with:

  • A description of the problem and the page it affects
  • Steps to reproduce it
  • The version and build number from the bottom of any page

Please don't include real invoice, vendor or bank details in your report.

What to expect

We'll acknowledge your report within [3 working days] and keep you updated until it's fixed.

Please don't

  • Access, change or delete data that isn't yours
  • Disrupt the service or run automated scans against the live system
  • Share details of the issue publicly before it's fixed

Suspected fraud

If you receive a suspicious request to change a vendor's bank details or to pay an invoice urgently, don't act on it. Contact your finance manager by phone using a number you already know.
